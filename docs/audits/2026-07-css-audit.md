# 2026-07 CSS 审计记录

## 已识别问题

- 登录页曾使用 `width: 106%`、大量 `vh` 和背景图拉伸来贴合手机截图，宽屏和 iPad 会变形。
- 产品库页面曾集中 1200 多行代码，页面、卡片、分析面板、弹窗和表单样式混在一起。
- 聊天页曾同时存在页面内消息样式和 `ChatMessage` 组件样式，职责重复。
- 档案表单曾把基础表单、脸型绘制和肤色选择器放在一个组件里。
- 断点曾分散为 380、480、640、768、769 等多个非系统化值。
- Vue 文件曾重复 `@use '@/assets/styles/variables' as *;`。

## 治理结果

- 登录页改为手机画布和宽屏居中策略。
- Product、Chat、Profile 页面已清空为纯净版空状态。
- 响应式统一使用 `respond()` mixin。
- 全局组件目录只保留跨模块组件。
- 主按钮统一为全局浅青玻璃质感，业务页不再保留私有深色按钮。
