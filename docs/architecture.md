# 项目架构规范

智颜当前处于 Clean App Baseline。项目只保留开屏、登录、基础身份、核心路由和空业务页面，后续功能从清晰模块边界中逐步添加。

## 核心模块

- `Splash`：开屏页，保持现有视觉。
- `Login`：登录页、社交登录入口、用户协议和隐私政策，保持现有视觉。
- `Profile`：个人档案入口，当前显示“暂无数据”。
- `Product`：产品库入口，URL 继续使用 `/cabinet`，当前显示“暂无数据”。
- `Chat`：AI 问答入口，当前显示“暂无数据”，不出现在侧边栏。

## 前端边界

页面放在 `frontend/src/views/<Module>/index.vue`。当前业务页面只保留空状态，不挂载旧表单、旧产品分析、旧聊天消息或旧模拟数据。

全局组件只放跨模块复用组件。所有按钮必须收口到全局 `.btn`、`.btn-primary`、`.btn-secondary`、`.btn-ghost`、`.btn-icon` 体系。

## 后端边界

后端使用模块化单体。当前只挂载健康检查和最小用户模块。聊天、产品库等业务 API 暂停暴露，后续按模块重新设计后再挂载。

## 数据库边界

数据库结构变化必须通过 Alembic migration。当前迁移链只创建最小 `users` 表；产品、聊天、档案详情等业务表后续按模块新增。

## 安全认证架构

为了保障项目后续升级为正式企业级系统的安全性，后端认证与加密体系做出以下规范：
* **零外部编译依赖慢哈希**：系统不引入需要底层 C 库在不同平台（Mac/Linux/Windows）进行编译安装的密码库（如 bcrypt），改用 Python 3 官方内置标准库 `hashlib.pbkdf2_hmac` 进行密码加密保护。
* **加盐散列规格**：使用安全随机源 `os.urandom(16)` 作为独立加盐，通过 SHA256 迭代 100,000 次进行加密。加盐值和哈希值以 `pbkdf2_sha256$100000$盐$哈希` 组合格式存储，可防范大部分彩虹表和爆破攻击，并保持跨平台零磨损流畅运行。
