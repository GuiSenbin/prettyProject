# 移动 H5 访问与部署说明

## 本地手机访问

1. 电脑和手机连接同一个 Wi-Fi。
2. 启动后端服务，确保 FastAPI 监听局域网地址，例如 `0.0.0.0:8000`。
3. 启动前端开发服务，确保 Vite 监听局域网地址。当前项目默认端口是 `6688`。
4. 在手机浏览器访问 `http://电脑局域网IP:6688`。

如果前端请求不到后端，配置 `VITE_API_BASE_URL` 指向可被手机访问的后端地址，例如：

```bash
VITE_API_BASE_URL=http://电脑局域网IP:8000/api
```

本地开发默认也可以通过 Vite 代理访问后端：

```bash
VITE_API_PROXY_TARGET=http://电脑局域网IP:8000
```

## 正式部署

- 前端部署到支持 HTTPS 的静态站点或对象存储。
- 后端部署到公网服务，并使用 HTTPS 域名。
- 前端生产环境配置 `VITE_API_BASE_URL=https://你的后端域名/api`。
- 如果后续封装应用商店 App，建议继续复用这套 H5 页面和 HTTPS API。

## 小程序方向

当前 Vue Web 项目不能直接作为微信小程序发布。若要做小程序，建议另建 uni-app、Taro 或原生小程序前端，并复用现有 FastAPI 后端接口。
