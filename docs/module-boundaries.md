# 模块边界

## Login

负责登录页、社交登录按钮、协议弹窗和本地登录态入口。不负责用户档案编辑。

## Splash

负责开屏展示。不承载业务状态。

## Profile

负责用户个人护肤档案的采集与维护，包含性别、年龄、肤质、肤色、脸型、皮肤问题、安全避雷和偏好注意事项。档案详情由后端 `profiles` 模块和 `user_profiles` 表独立承载，不写入 `users` 账号主表。

## Product

当前只保留产品库入口和空状态。添加产品、删除产品、反馈、产品分析都暂停，后续作为产品模块能力重新设计。

## Chat

当前只保留 AI 问答入口和空状态，不出现在侧边栏。聊天输入、历史、提示词和 AI 回复规则后续重新设计。

## 全局规则

业务模块不得使用旧模拟数据。新增能力必须先明确所属模块，再补页面、API、service、repository 和 migration。
