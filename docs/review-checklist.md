# 交付前审核清单

## 前端

- [ ] 页面目录使用 `views/<Module>/index.vue`。
- [ ] 模块组件位于对应 `views/<Module>/components/`。
- [ ] 全局 `components/` 只保留跨模块组件。
- [ ] Vue 文件没有重复 `@use '@/assets/styles/variables' as *;`。
- [ ] 已恢复的业务页符合对应模块边界；未恢复模块只保留顶部栏和“暂无数据”。
- [ ] 所有非登录页按钮使用全局按钮体系。
- [ ] API 调用通过 `frontend/src/api/<module>.js` 封装，store 和组件不直接拼后端 URL。
- [ ] 侧边栏不展示 AI 问答导航入口；Chat 历史只展示在退出登录上方的历史会话区。
- [ ] 正式、测试、本地环境通过 `.env.*` 区分，业务代码不写死环境域名。

## 响应式

- [ ] 手机宽度显示正常。
- [ ] iPad 竖屏显示正常。
- [ ] iPad 横屏显示正常。
- [ ] 桌面宽屏显示正常。
- [ ] 没有散乱手写 `@media`。

## 后端

- [ ] 后端模块位于 `backend/app/modules/`。
- [ ] API 层不直接堆复杂业务逻辑。
- [ ] service 负责业务判断。
- [ ] repository 负责数据库读写。
- [ ] 涉及用户隐私的接口从登录态解析用户，不信任客户端任意传入用户 ID。
- [ ] 没有启动时隐式删表逻辑。

## 数据库

- [ ] Alembic migration 可执行。
- [ ] 空库可初始化。
- [ ] 当前只创建最小 `users` 表。
- [ ] 数据库文件不进入版本控制。

## 旧逻辑残留

- [ ] 没有旧聊天提示词。
- [ ] 没有旧产品分析。
- [ ] 没有旧产品库本地存储工具。
- [ ] 没有旧达人或泛推荐逻辑。
