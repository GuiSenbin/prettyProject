# 交付前审核清单

## 前端

- [ ] 页面目录使用 `views/<Module>/index.vue`。
- [ ] 模块组件位于对应 `views/<Module>/components/`。
- [ ] 全局 `components/` 只保留跨模块组件。
- [ ] Vue 文件没有重复 `@use '@/assets/styles/variables' as *;`。
- [ ] 已恢复的业务页符合对应模块边界。
- [ ] 所有非登录页按钮使用全局按钮体系。
- [ ] API 调用通过 `frontend/src/api/<module>.js` 封装，store 和组件不直接拼后端 URL。
- [ ] 侧边栏不展示 AI 问答导航入口；Chat 历史只展示在退出登录上方的历史会话区。
- [ ] 正式、测试、本地环境通过 `.env.*` 区分，业务代码不写死环境域名。
- [ ] 产品库进入详情再返回时，搜索词、懒加载进度和滚动位置不丢失。
- [ ] AI 历史回看展示已保存的 `structured_payload`，不重新请求模型生成旧答案。

## 响应式

- [ ] 手机宽度显示正常。
- [ ] iPad 竖屏显示正常。
- [ ] iPad 横屏显示正常。
- [ ] 桌面宽屏显示正常。
- [ ] 没有散乱手写 `@media`。

## 后端

- [ ] 后端模块位于 `backend/app/modules/`。
- [ ] API 层不直接堆复杂业务逻辑。
- [ ] service 负责业务判断。
- [ ] repository 负责数据库读写。
- [ ] 涉及用户隐私的接口从登录态解析用户，不信任客户端任意传入用户 ID。
- [ ] 没有启动时隐式删表逻辑。

## 数据库

- [ ] Alembic migration 可执行。
- [ ] 空库可初始化。
- [ ] 当前表结构包含账号、个人档案、产品库、成分、个人产品库和 AI 问答相关表。
- [ ] 数据库文件不进入版本控制。

## AI 与产品逻辑

- [ ] 高风险和范围外问题不会绕过本地安全边界。
- [ ] DeepSeek 不可用、超时、返回非法 JSON 或校验失败时，可以回退到本地结构化答案。
- [ ] 当前上下文只读取最近 8 条消息；如果涉及长对话优化，必须设计长期摘要或压缩历史会话。
- [ ] 产品详情 Tips 基于产品成分和用户档案动态生成，没有档案时才展示补档案入口。
- [ ] 已加入个人产品库的产品不能重复添加，详情页显示已加入状态。
- [ ] “不方便透露”在产品适配中按未孕状态处理，不触发孕哺谨慎规则。
- [ ] 没有旧产品库本地存储工具。
- [ ] 没有旧达人或泛推荐逻辑。
